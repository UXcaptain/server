# UXcaptain - YouTube Video Ad Scripts (Spanish)

## Overview

**Product**: UXcaptain - Video-based user research platform for UX teams  
**Target Audience**: UX researchers, product managers, design leads at startups and small companies in Spain  
**Tone**: Conversational, benefit-focused, using informal "tú" form  
**Key Messages**: AI-powered analysis, automatic transcription, 10x cheaper, GDPR compliant, designed for small teams, remote testing

## 5. Video Ad Visual Directions Summary

### Bumper Ads (6s) - Visual Style

| Elemento | Descripción |
|----------|-------------|
| **Pacing** | Ultra rápido, cortes cada 1-2 segundos |
| **Estilo visual** | Bold, high contrast, colores de marca saturados |
| **Motion** | Animaciones snappy con easing exponencial |
| **Texto** | Máximo 5-6 palabras, tipografía bold, toda en mayúsculas opcional |
| **Logo** | Aparece en los últimos 2 segundos, con animación de entrada rápida |
| **CTA** | Implícito en el mensaje, URL en pantalla final |

### Non-Skippable (15s) - Visual Style

| Elemento | Descripción |
|----------|-------------|
| **Pacing** | Rápido pero comprensible, 3-4 escenas principales |
| **Hook visual** | Primeros 3 segundos: problema reconocible o pregunta directa |
| **Transiciones** | Cortes duros o wipes rápidos, ninguna disolución lenta |
| **Screen recordings** | 3-4 segundos de interfaz UXcaptain, mostrando resultado final |
| **Texto** | Palabras clave resaltadas ("IA", "GDPR", "10x más barato") |
| **CTA** | URL completa en pantalla + botón visual |

### Skippable (30s) - Visual Style

| Elemento | Descripción |
|----------|-------------|
| **Pacing** | Narrativo: lento al inicio, aceleración en solución |
| **Hook visual** | 5 segundos de storytelling emocional (reconocible para UX researchers) |
| **Arquitectura visual** | Split screens, motion graphics explicativos |
| **Screen recordings** | 10-12 segundos totales, mostrando flujo completo del producto |
| **Testimonios visuales** | Fotos de usuarios reales (si disponible) o avatares representativos |
| **CTA** | URL + beneficios claros + urgencia suave |

### Discovery Ads - Visual Style

| Elemento | Descripción |
|----------|-------------|
| **Pacing** | Educacional, ritmo conversacional |
| **Estilo visual** | Explainer video style, flat design, iconografía amigable |
| **Screen recordings** | 40-50% del video, mostrando funcionalidades reales |
| **Motion graphics** | Diagramas, flujos, comparaciones animadas |
| **Educación** | Subtítulos recomendados, pausas para procesar información |
| **CTA** | Soft sell, enfocado en valor educativo primero |

## Production Notes

### Technical Specs (YouTube Ads)

| Formato | Resolución | Aspect Ratio | Duración Max | Tamaño Max |
|---------|------------|--------------|--------------|------------|
| Bumper | 1920x1080 | 16:9 | 6s | 1GB |
| Non-Skippable | 1920x1080 | 16:9 | 15s | 1GB |
| Skippable | 1920x1080 | 16:9 | 3 min (recomendado 30s) | 1GB |
| Discovery | 1920x1080 | 16:9 | Sin límite | 1GB |

### Voiceover Guidelines

- **Acento**: Español neutro (preferiblemente español de España para target local)
- **Tono**: Conversacional, cercano, no corporativo excesivo
- **Pacing**: 
  - Bumper: 2 palabras/segundo
  - 15s: 2.5 palabras/segundo
  - 30s+: 2 palabras/segundo (pausas para énfasis)
- **Énfasis**: Palabras clave (IA, GDPR, gratis, 10x)

### Subtitles

- **Obligatorios**: Sí, para todos los formatos
- **Estilo**: Sans-serif bold, fondo semitransparente negro
- **Posición**: Bottom safe area (10% desde abajo)
- **Timing**: 0.2s antes del audio, 0.5s después

## Testing & Iteration

### A/B Test Recommendations

1. **Hook testing**: Problema vs Curiosidad vs Beneficio directo
2. **CTA testing**: "Empieza gratis" vs "Prueba 14 días" vs "Ver demo"
3. **Duración testing**: 15s vs 30s performance por objetivo de campaña
4. **Visual testing**: Screen recordings reales vs Animaciones explicativas

### KPIs a Trackear

- **View-through rate** (VTR) - especialmente importante para skippable
- **Click-through rate** (CTR)
- **Cost per view** (CPV)
- **Conversion rate** (signup trials)
- **View completion rate** por segmento de duración
