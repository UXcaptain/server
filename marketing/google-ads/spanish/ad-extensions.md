## Best Practices for Spanish Extensions

### Character Limits Reference
| Extension Type | Max Characters |
|----------------|----------------|
| Sitelink Text | 25 |
| Sitelink Desc 1 | 35 |
| Sitelink Desc 2 | 35 |
| Callout Text | 25 |
| Structured Snippet Header | 24 |
| Structured Snippet Values | 25 each |

### Tone Guidelines
- Use "tú" form consistently
- Imperative for CTAs ("Ver", "Probar", "Empezar")
- Include accent marks properly (tildes)
- Keep it punchy and benefit-focused

### Cultural Considerations
- Mention "España" for local relevance
- Reference GDPR/privacy prominently
- Use euros (€) for currency
- Spanish business hours (CET)

### Testing Recommendations
1. Test "Empezar Gratis" vs "Probar Gratis" sitelinks
2. Test price-focused vs feature-focused callouts
3. Test "GDPR" vs "Cumple RGPD" messaging
4. Test "10x Más Barato" vs "Desde €0/mes" callouts
